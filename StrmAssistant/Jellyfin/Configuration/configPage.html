🎬 StrmAssistant for Jellyfin

Jellyfin 媒体服务器功能增强插件 - 提供媒体信息提取、片头检测、多版本合并、中文搜索等功能

⚙️ 功能开关

使用 FFProbe 提取详细的媒体流信息并持久化到数据库
使用音频指纹自动检测片头片尾并创建 MediaSegment（需要 Jellyfin 10.10.0+）
自动合并同目录下的不同质量版本（4K、1080p 等）
支持繁简混合、拼音首字母搜索
独立扫描外挂字幕文件并自动关联
中文内容按拼音首字母排序
输出详细日志信息，用于问题排查

💾 媒体信息持久化

将提取的媒体信息保存为 JSON 文件，便于备份和迁移
默认行为（留空）：JSON 文件保存在媒体文件所在的同一目录下
例如：/media/movies/Movie.mp4 → /media/movies/Movie-mediainfo.json

自定义根目录：JSON 文件保存在指定根目录下，保持相对路径结构
例如：根目录设为 /backup/mediainfo，媒体文件 /media/movies/Movie.mp4
→ JSON 文件保存为 /backup/mediainfo/media/movies/Movie-mediainfo.json
注意：启用后，下次运行"提取媒体信息"任务时，会重新提取所有媒体的信息（忽略已有信息）。
任务执行完成后，此选项会自动关闭。

适用场景：
  • 媒体文件被替换或更新
  • 之前提取的信息不完整或错误
  • FFProbe 版本更新后重新扫描
  • 需要修复数据库中的媒体信息

📋 系统信息

插件版本: 0.0.4

目标 Jellyfin 版本: 10.10.0+

框架: .NET 8.0

📖 使用说明

  • 在 控制面板 → 计划任务 中可以看到所有 StrmAssistant 任务
  • 点击任务右侧的 ▶️ 按钮可以手动执行
  • 片头检测需要 Jellyfin 10.10.0+ 版本支持 MediaSegment API
  • 中文搜索和拼音排序会在搜索时自动生效
